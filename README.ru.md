# ⚡ SenixSearch

**Telegram-бот, который ищет свободные редкие юзернеймы и проверяет каждый вживую — и в Telegram, и на Fragment.**

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue?logo=python&logoColor=white)](https://www.python.org/)
[![python-telegram-bot](https://img.shields.io/badge/python--telegram--bot-21.x-2CA5E0?logo=telegram&logoColor=white)](https://python-telegram-bot.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

> 🇬🇧 English version — [README.md](README.md)

Большинство «чекеров ников» смотрят только на `t.me`. SenixSearch идёт дальше: он
дополнительно проверяет **[Fragment](https://fragment.com)** — официальную биржу
юзернеймов Telegram — и поэтому никогда не предложит ник, который на самом деле
продан, на аукционе или зарезервирован. Это разница между ником, который **можно
занять**, и ником, который просто **выглядит свободным**.

## ✨ Возможности

| | Функция | Описание |
|---|---|---|
| 🔍 | **Поиск свободных** | Генерирует кандидатов и отдаёт **только** реально занимаемые ники. |
| 5️⃣ | **Редкие 5-буквенные** | Почти все 5-буквенные скуплены Fragment — бот ищет ники с кластерами согласных (как `@xznow`), которые Fragment не трогал и которые свободны. |
| 🎭 | **Поиск по маске** | `a?b?c`, где `?` — любая буква. |
| ⭐ | **По рейтингу** | Самые редкие ники (длина, редкие буквы, уникальные символы). |
| 🪤 | **Ловушки** | Следит за занятым ником и уведомляет, как только он освободится. |
| 💎 | **Премиум-декор** | Анимированные Telegram Premium кастом-эмодзи прямо в тексте сообщений. |

Плюс: кнопочный интерфейс, дневные лимиты, Premium-тариф — всё в одном файле.

## 🧠 Как это работает (самое интересное)

**1. Проверка Telegram.** Запрос на `https://t.me/<ник>`. У публичной сущности
(юзер/бот/канал/группа) всегда есть блок `tgme_page_title`; у свободного ника его
нет. Выяснено эмпирически.

**2. Кросс-проверка Fragment.** Запрос на `https://fragment.com/username/<ник>` и
чтение статуса (`Available` / `Sold` / `Taken`) со страницы. Ник считается
**свободным**, только если он свободен в `t.me` **и** отсутствует на Fragment.

**3. Фишка с 5 буквами.** Telegram перевёл почти все «красивые» 5-буквенные ники на
аукционы Fragment — поэтому наивные генераторы выдают ники, которые нельзя занять
(«username is invalid»). А ники с кластерами согласных и редкими буквами
(`x z q j k w v`) на аукцион не попали и остаются свободными. Генератор делает
именно такие.

**4. Рендер премиум-эмодзи.** Telegram запрещает совмещать `parse_mode` с
кастом-эмодзи в одном сообщении. Поэтому в боте есть мини-рендерер, который сам
собирает entities для жирного/моноширинного текста **и** кастом-эмодзи (с верными
UTF-16 смещениями), с откатом, если у владельца бота нет Premium.

## 🛠 Стек

- **Python 3.10+**, полностью `async`
- **python-telegram-bot 21.x**
- **httpx** — асинхронный HTTP
- Хранилище — JSON-файл (без БД)

## 🚀 Запуск

```bash
# 1. Создай бота у @BotFather, скопируй токен
# 2. Укажи токен (одно из):
cp token.txt.example token.txt      # вставь токен внутрь
#    …или переменная окружения:  BOT_TOKEN=123456:ABC...

# 3. Установи зависимости
pip install -r requirements.txt

# 4. Запусти
python bot.py
```

На Windows можно просто запустить **`start.bat`**.

## 💬 Команды

| Команда | Что делает |
|---|---|
| `/start` | Главное меню (кнопки) |
| `/search <ник>` | Проверить один ник (Telegram + Fragment) |
| `/find <длина>` | Найти свободные ники нужной длины |
| `/mask a?b?c` | Поиск по маске (Premium) |
| `/trap <ник>` | Следить за ником, уведомить когда свободен (Premium) |
| `/rating` | Как считается рейтинг редкости |
| `/decor` | Демо премиум-эмодзи в тексте |
| `/setemoji <пак>` | Подключить свой набор `t.me/addemoji/...` |

## ⚠️ Примечания

- Доступность проверяется по публичным веб-сигнатурам (`t.me` + Fragment) — самый
  надёжный способ без пользовательской MTProto-сессии.
- Секреты и данные (`token.txt`, `users.json`, конфиги эмодзи) в `.gitignore` и
  никогда не коммитятся.
- Проект учебный / для портфолио, не связан с Telegram или Fragment.
